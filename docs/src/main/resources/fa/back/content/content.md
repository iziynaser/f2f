مدیریت وضعیت محتوا (ContentStatus)

مدیریت tags

۱. می‌توانیم روی طراحی سرویس‌های ماژول محتوا شروع کنیم.
برای شروع، معمولاً این سرویس‌ها تعریف می‌شوند:

ArticleService — مدیریت مقالات

ContentService — مدیریت محتوای عمومی (Content)

PageService — مدیریت صفحات (Page)

TagService (در صورت نیاز)

ContentStatusService (اختیاری برای مدیریت وضعیت محتوا)

و هر سرویس مرتبط با دسته‌بندی، کامنت و ...
////////////////////////////////////////////////////////////////////////////////////
سرویس‌های مدیریت دسته‌بندی محتوا (ContentCategoryService):
اتصال یک محتوا به دسته خاص

حذف اتصال محتوا از یک دسته

دریافت دسته‌های مرتبط با یک محتوا

دریافت همه محتواهای مرتبط با یک دسته خاص

بررسی وجود یک اتصال بین محتوا و دسته

دریافت محتواهای یک دسته همراه با وضعیت یا فیلتر دیگر (پیشرفته)
////////////////////////////////////////////////////////////////////////////////////////
