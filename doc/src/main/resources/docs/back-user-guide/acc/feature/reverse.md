سرویس برگشت تراکنش‌های حسابداری
چون سیستم بدون امکان “Reversal / Void / Cancel” در محیط عملیاتی قابل استفاده نیست.

کاربر باید بتواند:

تراکنش اشتباه را Reverse کند
تراکنش اصلاحی جدید ایجاد کند (اگر حساب تعدیلی داشته باشیم)
Ledger, Trial Balance و Period Balance ها را دوباره Sync کنیم
این سرویس هسته مرکزی پایداری سیستم است.
