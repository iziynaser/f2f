## مقدمه

این راهنما نحوه مدیریت دو فرانت اند مجزا (frontf برای کاربران و frontb برای مدیریت) را در قالب دو برنچ جداگانه Vue.js، به همراه استقرار آن‌ها در پروژه Spring Boot شرح می‌دهد. همچنین نحوه ساخت خودکار با اسکریپت Node.js ارائه شده است.


# نحوه ساختن این پروژه 

برای مستند سازی برنامه در حال توسعه از vitepress  استفاده شده است .
برای ساخت یک سایت مشابه برای مستند کردن برنامه می توانید از دستورات زیر استفاده کنید 

```md

## ایجاد پروزه

npm init vitepress@latest
cd docs
npm install
npm run docs:dev


### دسترسی 
http://localhost:5173

### بیلد کردن خروجی
npm run docs:build

### خروجی تولید شده 
docs/.vitepress/dist

```

## پشتیبان از زبان فارسی و راست چین کردن برنامه vitepress
برای این کار در فایل تنظیمات `config.mts `
تغیرات زیر را ایجاد می کنیم:
```
  lang: 'fa-IR',
  dir:'rtl',
```
سپس نیاز به نصب بسته زیر داریم که در ترمینال دستور زیر را وارد می کنیم:
```
 npm install rtlcss --sace-dev
```
