
## features
ساختاری که طراحی کرده‌اید برای مدیریت ویژگی‌های کالا (Product Features) به‌صورت سلسله‌مراتبی سه‌سطحی طراحی شده است:

ProductFeatureGroup → گروه ویژگی‌ها (مانند «مشخصات فنی»)

ProductFeatureItem → آیتم ویژگی (مانند «پردازنده»)

ProductFeatureItems → زیرآیتم یا مقدارهای خاص ویژگی (مانند «Intel i7»)

## s1
طراحی Category (درختی و عمومی)
ویژگی‌ها:

پشتیبانی از ساختار درختی از طریق فیلد parentCategory

قابلیت اتصال به CategoryType برای تفکیک دسته‌ها (مثلاً فروشگاهی، خدماتی، محتوا و...)

امکان استفاده در بخش‌های مختلف مانند:

کالاها (Product)

برندها (Brand)

مطالب وبلاگ، پرسش و پاسخ، تخفیف‌ها، کاربران و...

📌 این طراحی، Category را به یک ابزار همه‌کاره و reuseable تبدیل کرده که می‌تواند در کل سیستم استفاده شود بدون نیاز به ایجاد جداول اضافه برای هر use case.

## s2

طراحی ProductCategory (خاص برای کالاها)
ویژگی‌ها:

ساختار مستقل برای دسته‌بندی اختصاصی کالاها

دارای parentProductCategory برای ساختار سلسله‌مراتبی داخلی مخصوص کالاها

به دلیل نداشتن اتصال مستقیم به Product، قابل استفاده به‌عنوان قالب اولیه دسته‌بندی‌هاست

📌 از آن می‌توان در آینده برای تعریف منوی اصلی سایت یا فیلتر پیشرفته کالاها استفاده کرد.
