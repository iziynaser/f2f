## memory
میزان مموری مورد نیاز برای اجرای برنامه جقدر است ؟

ایجاد یک برنامه اینستالر که برنامه را براحتی بر روی سرور نصب کند
1. بصورت پیش فرض نصب کند
2. با اطلاعاتی مانند پورت ، ایکن برنامه ، نام شرکت نصب کند
3. با حالت پیشرفته مانند اطلاعات تستی جهت دمو نصب کند
4. با اطلاعاتی تکمیلی مانند محتواهای پیش فرض نصب کند.


ایجاد راهنمای کاربری برنامه برای دسترسی همگانی بر روی وب
ایجاد راهنمای سیستمی برای مدیریت سامانه های مختلف

راهنمایی برای تغیر پورت های برناکه

تنظیمات برنامه برای استفاده از اچ تی تی پی اس چگونه است ؟

## other

اطلاعات کلی و ثابت در موجودیت product نگهداری می شوند
اطلاعات متغیر وابسته به موجودی خاص در productItem



اگر لیست‌ها یا کالکشن‌ها از نوع یکسان (مثلاً Entity به EntityDTO) باشند و مپر مربوطه موجود باشد، MapStruct خودکار نگاشت می‌دهد.

اگر کالکشن‌ها از نوع متفاوت (مثلاً Entity به List`<Long>`) باشند، باید متدهای کمکی بنویسید.

    با @Named و qualifiedByName می‌توانید به MapStruct بگویید کدام متد کمکی را برای نگاشت استفاده کند.

    اگر می‌خوای، برات نمونه کامل‌تر و پروژه محور بزنم تا دقیق‌تر دستت بیاد. یا می‌خوای برای هر رابطه خاص مثال بزنم؟
