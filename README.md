# f2fCore – Backend Server

📘 این پروژه یک **backend مالتی ماژول Spring Boot** است و به عنوان پروژه آموزشی (Project Based Learning) برای Spring Boot و Java طراحی شده است.

> ⚠️ توجه
> این پروژه برای **کار عملی واقعی توصیه نمی‌شود** و بیشتر برای یادگیری و نمونه‌سازی مناسب است.

---

## 🎯 اهداف
- یادگیری و تست مفاهیم Spring Boot و Java
- ارائه نمونه ماژول‌های متعدد در یک پروژه مالتی ماژول
- فراهم‌کردن ساختار برای مستندات و مشارکت توسعه‌دهندگان

---

## 🗂 ماژول‌ها
این پروژه شامل ماژول‌های زیر است:

1. dbc ماژول پایه
2. frontb واسط کاربری بک آفیس
3. frontf واسط کاربری مشتری
4. content ماژول محتوا برای نمایش داده ها و محتوا ها بر روی سایت
5. acc
   6. ماژول حسابداری
6. hr ماژول منابع انسانی
7. order ماژول سفارشات
8. asset ماژول دارایی ها
9. budget ماژول بودجه
10. delivery
11. f2f-i18n
12. skript
13. logging
14. images
15. shopping
16. product ماژول کالا
17. promotion ماژول تحفیفات
18. inventory مازول انبار
19. payment ماژول پرداخت
20. reporting ماژول گزارش گیری
21. purchase ماژول خرید
22. sales ماژول فروش
23. invoice ماژول فاکتور
24. f2fc
25. catalog ماژول کاتالوگ
26. comment ماژول نظرات
