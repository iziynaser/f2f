# verjik  –  

📘 این پروژه یک **backend مالتی ماژول Spring Boot** است و به عنوان پروژه آموزشی (Project Based Learning) برای Spring Boot و Java طراحی شده است.
ماژول های لایه فرانت با استفاده از vuejs , vite press توسعه داده شده است.

> ⚠️ توجه
> نسخه های اولیه برای کار عملی توصیه نمی شود. برای استفاده می توانید از نسخه های منتشر شده ریلیز استفاده نمایید
> سورس پروژه بیشتر برای یادگیری و نمونه سازی مناسب است
>برای استفاده از سرویس های ارائه شده می توانید بصورت مستقیم از کلاینت های بک افیش و کلاینت مشتری تولید شده برای این اپلیکشن استفاده کنید
> f2fuib,f2fuif برای این منظور توسعه داده شده است
>نسخه های ریلیز تمامی فیچرها بصورت مجتمع و یکپارچه جهت استفاده قرار داده شده است.
---

## 🎯 اهداف
- یادگیری و تست مفاهیم Spring Boot و Java
- ارائه نمونه ماژول‌های متعدد در یک پروژه مالتی ماژول
- فراهم‌کردن ساختار برای مستندات و مشارکت توسعه‌دهندگان
- یکپارچه سازی لایه بک اند با لایه های فرانت و استفاده از vuejs برای این منظور
---

## مستندات
- برای بررسی بیشتر می توانید به مستندات پروژه که در ماژول doc قرار دارد مراجعه کنید فایل های این بخش
- بصورت فایل های mardown می باشند که براحتی قابل استفاده است
